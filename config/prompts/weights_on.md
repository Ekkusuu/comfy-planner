This workflow reads prompt weights. To stress a tag, write it as `(tag:1.4)`: round brackets around one tag or short phrase, a colon, a number. Use them sparingly: only for a concrete object or feature that the brief stresses ("must", "really", "make sure", "the focus", "don't forget") or that must not get lost. Never put a weight on a quality tag, a trigger word, a style tag, or in negative_additions. Numbers from 1.2 to 1.8, 1.4 unless the brief asks for more. At most 3 weights in a prompt. No weights at all is a fine and common answer: a neutral brief gets none. Never nest brackets or write `((x))`. Round brackets are for nothing else, except inside a name that already has them, like `aria vale (starlight)`. A weight the user wrote in the job themselves, like `(forest:2.5)`, is theirs: copy it into every prompt exactly as written, with its own number.
